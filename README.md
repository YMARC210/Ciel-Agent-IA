# Ciel-Agent-IA
Agent IA local autonome développé en Python avec Qwen2.5-1.5B, Streamlit, ChromaDB et outils personnalisés.# 🌌 CIEL V7.0 — Agent IA Local Autonome

**CIEL V7.0** est un agent IA autonome conçu pour tourner localement sur du matériel limité, utilisant **Qwen2.5-1.5B**, **Streamlit**, et **ChromaDB** pour la mémoire vectorielle.

## 🛠️ Architecture & Modules
* **Ciel.py** : Interface Streamlit et orchestration principale.
* **moteur_grounding.py** : Moteur de recherche et d'ancrage contextuel.
* **calcul.py** : Module de calcul mathématique et d'exécution sécurisée.
* **outils_scolaires.py** : Outils de résolution de problèmes scolaires.
* **outils_ciel.py** : Outils système, automatisation et synthèse vocale.
